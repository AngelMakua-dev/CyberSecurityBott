#Cybersecurity Awareness Chatbot 
#Project Overview POE PART 2

This project is a Cybersecurity Awareness Chatbot developed using C# and WPF (Windows Presentation Foundation). The chatbot has been upgraded from a command-line application to a graphical user interface (GUI) to improve user experience and interactivity.

The system provides cybersecurity guidance, detects user sentiment, remembers user details, and responds dynamically based on user input.

Features
 Graphical User Interface (GUI)
Built using WPF
Clean, user-friendly layout
Includes chat display area, input box, and send button
Styled interface with colors and spacing for better usability
ASCII art converted into GUI visual elements / labels

 Keyword Recognition
The chatbot recognizes cybersecurity-related keywords such as:
Password
Scam / Phishing
Privacy
It responds with relevant cybersecurity advice depending on detected keywords.

 Random Response System
Uses lists/arrays of predefined responses
Randomly selects responses for topics like phishing tips
Ensures more natural and less repetitive conversations

 Conversation Flow
Supports follow-up inputs such as:
“tell me more”
“another tip”
“explain further”
Maintains topic continuity without restarting conversations
Provides smooth and natural dialogue flow

 Memory and Recall System
Stores user details such as:
Name
Interests (e.g., privacy, passwords, scams)
Uses stored data in future responses
Personalizes cybersecurity advice based on user preferences

 Sentiment Detection
The chatbot detects basic user emotions such as:
Worried
Curious
Frustrated
It adjusts responses accordingly:
Supportive tone for worried users
Encouraging tone for confused users
Informative tone for curious users
