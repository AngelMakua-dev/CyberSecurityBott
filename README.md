#Cybersecurity Awareness Chatbot 
#Project Overview POE PART 2

This project is a Cybersecurity Awareness Chatbot developed using C# and WPF (Windows Presentation Foundation). The chatbot has been upgraded from a command-line application to a graphical user interface (GUI) to improve user experience and interactivity.

The system provides cybersecurity guidance, detects user sentiment, remembers user details, and responds dynamically based on user input.

Features
 Graphical User Interface (GUI)
Built using WPF
Clean, user-friendly layout
Includes chat display area, input box, and send button
Styled interface with colors and spacing for better usability
ASCII art converted into GUI visual elements / labels

 Keyword Recognition
The chatbot recognizes cybersecurity-related keywords such as:
Password
Scam / Phishing
Privacy
It responds with relevant cybersecurity advice depending on detected keywords.

 Random Response System
Uses lists/arrays of predefined responses
Randomly selects responses for topics like phishing tips
Ensures more natural and less repetitive conversations

 Conversation Flow
Supports follow-up inputs such as:
“tell me more”
“another tip”
“explain further”
Maintains topic continuity without restarting conversations
Provides smooth and natural dialogue flow

 Memory and Recall System
Stores user details such as:
Name
Interests (e.g., privacy, passwords, scams)
Uses stored data in future responses
Personalizes cybersecurity advice based on user preferences

 Sentiment Detection
The chatbot detects basic user emotions such as:
Worried
Curious
Frustrated
It adjusts responses accordingly:
Supportive tone for worried users
Encouraging tone for confused users
Informative tone for curious users

Cybersecurity Awareness Chatbot – Part 3

Overview

This project is a Cybersecurity Awareness Chatbot developed using C# and WPF. It is designed to educate users about cybersecurity while providing interactive features to improve user engagement and awareness.

Features

Chatbot

- Provides cybersecurity advice on topics such as passwords, phishing, scams, privacy, malware, VPNs, and two-factor authentication.
- Remembers user information from previous interactions.
- Detects user sentiment and responds appropriately.
- Uses keyword recognition to answer cybersecurity-related questions.

Task Assistant

- Allows users to create cybersecurity-related tasks.
- Users can add task titles, descriptions, and reminder dates.
- Tasks can be viewed, managed, marked as completed, or removed.
- Tasks are intended to be stored using a MySQL database.

Cybersecurity Quiz

- Includes multiple-choice and True/False cybersecurity questions.
- Displays one question at a time.
- Provides immediate feedback after each answer.
- Keeps track of the user's score and displays the final result.

Natural Language Processing (NLP) Simulation

- Uses keyword detection and simple string matching to understand different ways users phrase requests.
- Recognises commands related to tasks, reminders, quizzes, and cybersecurity topics without requiring exact wording.

Activity Log

- Records important chatbot actions such as adding tasks, setting reminders, starting quizzes, completing quizzes, and recognised NLP commands.
- Displays a summary of recent activities when requested by the user.

Technologies Used

- C#
- WPF (Windows Presentation Foundation)
- XAML
- MySQL
- Visual Studio 2022
